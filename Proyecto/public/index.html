Componentes:

  • 🎨 Capa de Presentación (Frontend HTML/CSS/JavaScript)
  • ⚙️ Capa de Lógica de Negocio (Node.js/Express)
  • 💾 Capa de Datos (SQLite)

Despliegue: Un único nodo con separación lógica estricta entre capas
